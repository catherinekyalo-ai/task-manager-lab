# Task Manager

A menu-based Python program to add tasks, mark them complete, view pending tasks, and track progress.

## Structure
- `main.py`: menu interface
- `task_manager/task_utils.py`: add, complete, view, progress functions
- `task_manager/validation.py`: title, description, due date validation

## Run
`python3 main.py`
